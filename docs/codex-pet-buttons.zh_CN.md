# Codex 电子宠物按键说明

本文对应当前电子宠物应用，包含新增的“会话／项目列表长按下键返回宠物”操作。
设备需刷入对应固件后才能使用这个新操作。配网和电脑桥接器的完整说明见
[应用指南](codex-pet.zh_CN.md)。

## 按键与操作方式

- **UP（上键）**、**DOWN（下键）**、**OK（确认键）**是软件可读取的三个功能键。
- **短按**：按下后松开一次。**长按**：持续按住约 **0.5 秒**，直到触发长按操作。
- **Power（电源键）**独立控制硬件电源，当前 BSP 没有它的软件事件接口，不能用作返回或导航键。
- **双击没有分配操作**，不支持 UP+DOWN 同按手势；每次使用一个功能键。

## 返回宠物与重新进入

- **在会话或项目列表长按下键**，立即返回宠物。选中位置保留；这个本地导航不会取消电脑聊天或发送消息。
- **在宠物页短按任意功能键**，重新打开记忆的列表。打开页面的第一次短按不会同时移动选择、开始录音、发送语音或允许审批；未完成的语音预览或审批会恢复原页面。
- 项目和会话列表在首尾循环切换；语音预览和审批内容也在首尾循环翻页。
- **10 秒没有按键操作**，交互页面自动返回宠物，Codex 正在工作时也一样。桥接心跳和状态更新不会延长计时；录音／转写期间保持当前页面，完成后重新开始 10 秒计时。
- 自动返回不会提交电脑草稿或作出审批决定。退出语音预览会保留电脑草稿，删除文字在电脑操作；需要明确拒绝请求时，使用审批页的对应按键。
- 返回宠物后，先松开下键，再次长按下键才会进入 Wi-Fi 配置；返回操作本身不会进入配网。

## 语音、审批与新会话细节

- 语音功能需要在线交互桥接器，以及选中的现有聊天或已准备的新聊天草稿。录音、转写和预览期间，目标聊天或新聊天项目保持不变。空会话列表仍不能直接录音；返回项目列表并长按 UP 准备新聊天。
- OK 长按被识别后开始录音；看到 `RECORDING` 再说话。松开 OK 结束，录音最长 30 秒。松开后转写，并请求用设备转写文字填入所选聊天的电脑输入框；另行短按 OK 才将这些转写文字提交到所选聊天。
- 未识别到语音或转写失败时，短按任意功能键关闭错误提示。这次短按只关闭提示，不会移动选择或发送内容。选中的聊天或已准备的新聊天草稿会保留，随后长按 OK 即可再次录音。长按 UP 或 DOWN 也能关闭错误。短按恢复需要刷入更新后的固件；桥接器也需更新以显示匹配的语音错误操作提示。
- 语音预览页长按 OK 可补充录音，追加到设备转写文字后，用完整累积语音填入电脑输入框。电脑已有输入会被替换，不合并原文。设备不读取电脑输入、不跟踪电脑编辑、不感知电脑发送／清空，也不等待填入确认。短按 OK 只发送设备的语音文字，即使电脑输入已编辑或清空。填入失败时仍保留转写，不要求 PC 输入确认。退出预览保留电脑文字，下次录音从新转写开始。设备发送后电脑输入可能保留，由用户在电脑处理；提交结果未确认时，请在电脑检查聊天后再决定是否重试。
- 审批页短按上键翻到下一页，短按下键立即拒绝。全部页面都显示过后，短按 OK 才能允许请求。长按上键或下键都会拒绝，不能当作不作决定的“返回宠物”操作。
- 在已保存的本地项目上长按 UP，准备设备草稿。长按 OK 录音，松开转写，再短按 OK 创建聊天并发送首条语音。新聊天的转写在确认前只保留在设备，不填入电脑输入框；预览中再次长按 OK 可补充语音。取消、预览过期或重复确认都不会自动创建或重发聊天。
- 第一轮使用本机 Codex CLI、现有登录和 CLI 配置，不添加绕过权限或 Hook 信任的参数。该进程退出后，桥接器在桌面打开已保存聊天，发现后自动选中。现有聊天的后续消息仍使用桌面 IPC。CLI 首轮运行期间，桥接器不会打开该聊天或向它发送另一轮；也请勿在电脑手动打开。保持桥接器运行，使用 Ctrl+C 正常停止可终止待完成首轮。结果不确定时，先在电脑检查再决定是否重试。`No project`、不可访问的目录以及多个项目共用同一根目录均不能使用此快捷入口。

## Wi-Fi 配置与断线情况

- **在宠物页长按下键**进入 Wi-Fi 配置，设备会重启到配网热点模式。
- 配网时短按 OK，切换加入热点二维码与配网页面二维码。先连接设备热点，再打开 `http://192.168.4.1/`。其他按键手势没有导航操作，后续配置在手机／浏览器完成。
- 联网成功后保存 Wi-Fi 配置，经过 8 秒状态显示窗口后自动重启。没有通过功能键“退出配网”的操作。
- 未连接交互桥接器时，基础宠物页支持短按 OK 互动、长按下键配网。控制数据过期时，不会切换聊天、发送语音或作出审批决定，也不会把原有 OK 操作转换成宠物互动。

## 验证范围

长按下键返回的实现已通过固件编译和主机测试。实体按键响应、屏幕提示，以及返回后重新进入能否保留选择，仍需在刷入该固件的设备上测试。
