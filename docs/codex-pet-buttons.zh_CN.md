# Codex 电子宠物按键说明

本文对应当前电子宠物应用，包含新增的“会话／项目列表长按下键返回宠物”操作。
设备需刷入对应固件后才能使用这个新操作。配网和电脑桥接器的完整说明见
[应用指南](codex-pet.zh_CN.md)。

## 按键与操作方式

- **UP（上键）**、**DOWN（下键）**、**OK（确认键）**是软件可读取的三个功能键。
- **短按**：按下后松开一次。**长按**：持续按住约 **0.5 秒**，直到触发长按操作。
- **Power（电源键）**独立控制硬件电源，当前 BSP 没有它的软件事件接口，不能用作返回或导航键。
- **双击没有分配操作**，不支持 UP+DOWN 同按手势；每次使用一个功能键。

## 返回宠物与重新进入

- **在会话或项目列表长按下键**，立即返回宠物。选中位置保留；这个本地导航不会取消电脑聊天或发送消息。
- **在宠物页短按任意功能键**，重新打开记忆的列表。打开页面的第一次短按不会同时移动选择、开始录音、发送语音或允许审批；未完成的审批或新聊天草稿会恢复原页面。
- 项目和会话列表在首尾循环切换；审批内容也在首尾循环翻页。
- **10 秒没有按键操作**，交互页面自动返回宠物，Codex 正在工作时也一样。桥接心跳和状态更新不会延长计时；录音／转写期间保持当前页面，完成后重新开始 10 秒计时。
- 自动返回不会提交电脑草稿或作出审批决定。退出会话列表会保留电脑草稿，删除文字在电脑操作；需要明确拒绝请求时，使用审批页的对应按键。
- 返回宠物后，先松开下键，再次长按下键才会进入 Wi-Fi 配置；返回操作本身不会进入配网。

## 语音、审批与新会话细节

- 语音需要在线桥接器，以及选中的聊天或已准备的新聊天草稿。录音和转写期间目标固定。看到 `RECORDING` 再说话，松开 OK 转写，录音最长 30 秒。
- 现有聊天的转写填入电脑输入框后回到会话列表，卡片不显示或保存转写文字。短按 OK 发送电脑输入框当前文字，包括电脑编辑；没有录音也可以发送。输入为空或已清空时不发送，不回退到缓存语音。
- 连续录音在桥接器内存中累积，直到发送或离开所选聊天。填入会用累积语音替换电脑输入，并短暂等待确认。保存延迟时保留待确认状态并返回列表，不误报填入失败；Confirm 会等待新的电脑文字，不能发送此前旧输入。等待、返回宠物和重连保留桥接草稿，重启桥接器后丢失。补充转写失败保留此前语音及电脑文字；未确认填入时需检查电脑实际输入。选择记录文件不保存转写。
- 语音或填入失败后，短按任意功能键关闭提示；这次短按只关闭提示，不发送或决定审批。此前列表、审批或新聊天草稿仍可继续录音。
- 审批页上键翻页，下键立即拒绝。全部页显示过后，短按 OK 确认。长按 OK 转写并填入电脑，随后恢复同一请求，不发送或决定审批。长按上键或下键拒绝请求。
- 在已保存项目长按 UP 准备新聊天草稿，录制首条消息后在通用待发送提示页短按 OK 创建并提交。文字只留在桥接器内存，卡片不显示转写；再次长按 OK 可追加。取消或重复事件不会自动创建或重发。项目导航及宠物唤醒保留正常的选择、打开行为。
- 新聊天首轮使用本机 Codex CLI、现有认证与配置，退出后在桌面打开并选中该聊天。现有聊天发送使用桌面执行实例 IPC。CLI 首轮运行期间请勿在电脑手动接管。失败或不确定的发送应先在电脑检查再决定重试；IPC 发送后电脑输入可能仍保留，需要时在电脑清空。

## Wi-Fi 配置与断线情况

- **在宠物页长按下键**进入 Wi-Fi 配置，设备会重启到配网热点模式。
- 配网时短按 OK，切换加入热点二维码与配网页面二维码。先连接设备热点，再打开 `http://192.168.4.1/`。其他按键手势没有导航操作，后续配置在手机／浏览器完成。
- 联网成功后保存 Wi-Fi 配置，经过 8 秒状态显示窗口后自动重启。没有通过功能键“退出配网”的操作。
- 未连接交互桥接器时，基础宠物页支持短按 OK 互动、长按下键配网。控制数据过期时，不会切换聊天、发送语音或作出审批决定，也不会把原有 OK 操作转换成宠物互动。

## 验证范围

长按下键返回的实现已通过固件编译和主机测试。实体按键响应、屏幕提示，以及返回后重新进入能否保留选择，仍需在刷入该固件的设备上测试。
